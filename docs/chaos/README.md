# Chaos Engineering

This directory stores failure-injection scenarios and experiment results.

## Initial experiment set

- DB latency injection
- DB unavailability
- Redis outage
- Memcached outage
- MongoDB analytics sink outage
- duplicate message delivery
- slow downstream dependency
- realtime connection storm
- authorization policy rule mismatch
- rate limit backend counter failure
- network latency and packet loss

## Required outputs

- hypothesis
- blast radius
- experiment steps
- observed behavior
- metrics and traces
- remediation items
