# System Context

## Purpose

Define the platform boundary, primary actors, and external dependencies for the collaboration platform.

## Primary actors

- workspace member
- workspace admin
- platform operator
- AI-assisted end user
- internal support / operations staff

## External systems

- identity provider
- email / notification providers
- object storage
- payment provider if premium tenancy is introduced
- observability stack
- AI model / embedding providers

## Platform boundary

The platform owns:

- tenant and workspace management
- identity integration and session flows
- collaboration features
- search and retrieval
- audit logging
- operational telemetry
